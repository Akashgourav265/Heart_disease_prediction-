# ❤️ Heart Disease Prediction using Machine Learning

A machine learning web application that predicts the likelihood of heart disease based on patient health and clinical information.

The project uses a **K-Nearest Neighbors (KNN)** classification model and provides an interactive user interface built with **Streamlit**.

---

## 📌 Project Overview

Heart disease is one of the major health concerns worldwide. Machine learning can be used to analyze clinical features and identify patterns associated with heart disease.

This project demonstrates an end-to-end machine learning workflow:

- Data exploration and analysis
- Data preprocessing
- Categorical feature encoding
- Feature scaling
- Model training
- KNN classification
- Model evaluation
- Saving the trained model
- Building an interactive Streamlit application
- Making predictions from user-provided inputs

The final application allows users to enter patient information and receive a model-based heart disease risk prediction.

> ⚠️ **Disclaimer:** This project is intended for educational and demonstration purposes only. It is not a medical diagnostic tool and should not be used as a substitute for professional medical advice.
